- Source project: https://invent.kde.org/frameworks/breeze-icons
- Original path: `icons/preferences/32/preferences-desktop-touchscreen.svg`
- Copied from Fedora package `breeze-icon-theme-6.31.0-1.fc44.noarch`.
- Exact installed source and SHA-256 are recorded in `kde-touchscreen.source.json`.
- The original artwork-library notice and LGPL terms are retained in
  [COPYING-ICONS](licenses/breeze-icons/COPYING-ICONS).
- The incorporated GPL version 3 text is retained in
  [GPL-3.0.txt](licenses/breeze-icons/GPL-3.0.txt).

The SVG is the editable source artwork and has not been redrawn, recoloured or
otherwise modified. These notices apply to this KDE icon, not to the original
RedCat artwork stored elsewhere in this project.

The installed KDE System Settings module names this icon in
`kcm_touchscreen.desktop`. This version uses a multicolour screen with a hand and
touch rings. The supplied reference screenshot uses a flat-blue variant, which
was not present in the installed icon themes.
