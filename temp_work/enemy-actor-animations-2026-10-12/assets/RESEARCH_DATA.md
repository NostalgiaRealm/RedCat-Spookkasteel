# Animation pose measurements

`rebuild-samples.jsonl.gz` contains the complete, losslessly compressed native-comparison measurement file. It is compressed for GitHub/GitLab distribution; the unpacked file is too large for normal GitHub Git storage.

- Uncompressed bytes: 164682243
- SHA-256 of uncompressed data: `3307365aaa90af9f97dad942a904a305085b858909e83548577f981babf8a54e`

Read without extracting: `gzip -dc rebuild-samples.jsonl.gz`. To recreate the original local file for an analysis script: `gzip -dk rebuild-samples.jsonl.gz`. The uncompressed working copy is ignored by Git.
